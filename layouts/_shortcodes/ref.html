{{- /* A *second* marker for a note that {{< sidenote >}} has already emitted — the rare case where one note is referenced twice. The number is required: {{< sidenote >}} owns the counter, so there is nothing sensible to auto-number against here, and guessing would silently point the marker at the wrong note. This marker carries no `snref:N` id — the note's own backlink already points at the primary marker, and a duplicate id would be invalid anyway. */ -}} {{- $n := .Get 0 -}} {{- if not $n -}} {{- errorf "%s: {{< ref >}} needs the number of the note it points at, e.g. {{< ref 3 >}} alongside {{< sidenote num=\"3\" >}}" .Position -}} {{- end -}} {{ printf "%02d" (int $n) }}
